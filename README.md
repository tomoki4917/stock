# 投資学習ツール

## 学習の目的
将来に向けて投資判断能力を養う。

投資判断能力の定義：
1. **情報収集能力** ← 今ここ
2. 情報分析能力
3. 仮説構築能力
4. 売買判断能力
5. リスク管理能力
6. 振り返り・改善能力

## 実践の前提
- 積み立てNISA：オルカン 毎月5万円（コア）
- 成長NISA / 個別株売買：長期＋スイング（サテライト、銘柄未定）
- 毎日、株に時間を割く

## 学習者プロフィール（2026-08-11 更新）
- レベル：初心者（用語レベルから学ぶ。宿題には必ずヒント・調べる手がかりを付ける）
- 宿題の時間：1日30分程度
- **監視銘柄（成長NISA・個別株の買い候補）** — `監視銘柄.json` で管理（スマホアプリから編集可）
  - 東京エレクトロン（8035）— 半導体装置
  - トヨタ自動車（7203）— 自動車
  - 三菱UFJフィナンシャル・グループ（8306）— 銀行
- 宿題はマクロ（市場全体）＋監視銘柄の材料＋実践スキル（売買判断の言語化）を毎日回す
- オルカン積立はコア、監視銘柄はサテライトとして体系的に学ぶ

## 運用ルール（宿題サイクル）
1. AIが市場ニュースを収集し、`宿題/` フォルダに宿題ファイルを作成する
2. あなたがファイル内の「分析課題」に自分の言葉で回答を書き込む
3. 書き終えたらAIに提出（チャットで「宿題やった、見て」でOK）
4. AIがフィードバックし、次の宿題を出す

### 宿題の約束事
- 正解を当てるのが目的ではない。**自分の頭で理由を言語化する**のが目的
- わからない用語が出たら、それ自体を調べるのも情報収集の訓練
- 回答は箇条書きでOK。ただし「なぜそう思うか」を必ず1行添える

## スマホ（iPhone）での使い方
このフォルダはGitHubの非公開リポジトリと同期している。

### スマホで宿題を見る・書く（宿題ノートアプリ）
専用Webアプリ「宿題ノート」を使う：https://tomoki4917.github.io/stock-app/

1. Safariで上のURLを開く（初回のみGitHubトークンを設定）
2. 宿題一覧から今日の宿題をタップ（または **監視銘柄** で買い候補を編集）
3. 設問ごとの回答欄に書き込み、下の「保存する（コミット）」をタップ

※ ホーム画面に追加しておくと便利：Safariで共有ボタン →「ホーム画面に追加」
※ アプリのソースは公開リポジトリ `stock-app`、宿題データはこの非公開リポジトリに保存される
※ 予備手段：github.com でファイルを直接開き、鉛筆アイコンから編集してもよい

### PC（Cursor）側のルール
- AIは宿題を作成したら必ず commit & push する（スマホから見えるようにする）
- AIは宿題を読む前に必ず git pull する（スマホでの書き込みを取り込む）

### AIフィードバックの書き方ルール
- **各設問の回答（引用ブロック）の直下**に「**AIコメント（月/日）**」の見出し＋箇条書きで書く（設問ごとに個別コメント）
- ファイル末尾の「AIからのフィードバック」欄には全体の総評を書く
- フィードバック部分に引用ブロック（行頭の `>`）は使わない（スマホアプリが回答欄と誤認するため）
- 学習者の回答（引用ブロック内）は絶対に書き換えない

## 自動化（完成フォーマット）

毎朝 **日本時間 4:00** に当日の宿題を自動作成する。

| 部品 | 役割 |
|------|------|
| `監視銘柄.json` | 買い候補銘柄リスト（宿題の中心。スマホアプリから編集） |
| `DAILY.md` / `自動化/宿題生成指示.md` | 宿題生成エージェントへの指示文 |
| `FEEDBACK.md` / `自動化/添削指示.md` | 回答提出後の添削エージェントへの指示文 |
| `.github/workflows/daily-homework.yml` | 毎朝4時（JST）に Cursor Cloud Agent を起動するスケジューラ |
| `.github/workflows/homework-feedback.yml` | 宿題回答の push を検知して AI 添削を起動 |

### 毎朝4時が動かないときのチェック（必須）
1. GitHub → Settings → Secrets → Actions に **`CURSOR_API_KEY`** があるか  
   （発行元: [Cursor Dashboard → API Keys](https://cursor.com/dashboard/api)）
2. Actions タブで **Daily homework** ワークフローが有効か（手動なら Run workflow で即テスト可）
3. Cursor 側で `tomoki4917/stock` への GitHub 書き込み連携が有効か（main へ直接 push する）

※ 指示ファイルだけではスケジュールは動かない。起動は GitHub Actions → Cursor API が担う。

### 添削（AIアドバイス）が届かないとき
1. 保存後、GitHub → Actions → **Homework feedback (Gemini)** が起動しているか確認
2. Secret **`GEMINI_API_KEY`** が設定されているか
3. 添削完了まで **1〜3分** 程度（Gemini API 直接呼び出し）
4. 手動で再実行: Actions → Homework feedback (Gemini) → Run workflow
5. 古い回答だけでは再実行されない場合がある → 宿題をもう一度保存する
